# Visual References

Use these products as references for principles, not as designs to copy.

## Notion

Study for:

- document-first hierarchy
- calm productivity UI
- lightweight navigation
- restrained use of borders
- document browsing
- template presentation
- contextual actions
- progressive disclosure

Do not copy:

- exact colors
- exact layouts
- branding
- iconography
- component structure

## Linear

Study for:

- precision
- compact interaction patterns
- command-like workflows
- strong alignment
- restrained surfaces
- polished hover/focus states
- efficient information density

Avoid making Syncpad feel like an issue tracker.

## Craft

Study for:

- editorial presentation
- document previews
- visual richness without excessive chrome
- typography
- document-focused composition

Avoid copying Craft's brand identity.

## Dropbox Paper

Study for:

- collaborative document simplicity
- writing-first interfaces
- lightweight chrome
- contextual editing actions

## Google Docs

Study primarily for interaction conventions:

- sharing
- collaborators
- comments
- document actions
- editor expectations

Do not use Google Docs as the primary visual reference.

Its value is familiarity and interaction conventions rather than
Syncpad's desired visual identity.

# Landing Page References

## Notion

Use Notion as the primary reference for:

- simplicity
- editorial hierarchy
- confident typography
- restrained navigation
- product-first storytelling
- friendly productivity branding
- whitespace
- clear CTA hierarchy

Study the feeling:

simple
human
productive
approachable
crafted

Do not copy:

- exact typography
- mascot style
- colors
- navigation structure
- exact hero composition

Syncpad should feel influenced by the same product philosophy, not like
a Notion clone.

---

## Blume

Reference:
https://blume.codes/

Use as a reference for:

- small crafted visual details
- product storytelling
- illustration integrated with UI
- clear sections
- playful but restrained personality
- strong relationship between copy and visuals

Blume should influence the landing page's personality more than its
product structure.

Do not copy its specific illustration language.

Use it as evidence that a technical/product website can remain minimal
while still having character.

---

## PatternCraft

Reference:
https://patterncraft.store/

Use for:

- subtle CSS background treatments
- geometric pattern ideas
- decorative background texture
- visual separation between large page regions

PatternCraft contains modern CSS/Tailwind background patterns and
gradients. Use these only when they support the composition.

Do not use a decorative pattern simply because empty space exists.

For Syncpad, patterns should be:

- low contrast
- sparse
- secondary to the product
- used in limited areas

Avoid turning the landing page into a pattern showcase.

# Reference Priority

For visual character:

1. Notion
2. Craft
3. Linear

For interaction conventions:

1. Google Docs
2. Notion

When references conflict, follow Syncpad's `design.md`.

Do not combine visible elements from several products into a collage.

Extract the underlying design principle and express it using the
Syncpad design system.
